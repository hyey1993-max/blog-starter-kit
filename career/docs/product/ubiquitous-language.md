# Ubiquitous Language — 커리어 판

도시 판의 용어를 그대로 쓰되 의미를 커리어에 맞게 옮긴다.

| Term | 커리어 판에서의 뜻 | Avoid |
|---|---|---|
| Flâneur | 자기 커리어를 관찰하며 걷는 사람 | user, candidate |
| Passage | 누군가 헤맨 커리어의 한 장면, 본인이 쓴 기록 | post, story card, case study |
| Thread | 자리가 바뀌어도 되풀이해 온 일 | skill, competency |
| Zone | 지도 위에서 하나의 Thread가 차지하는 영역 | job family, industry |
| Station | 거쳐 온 곳 (학교, 회사, 프로젝트) | employer history |
| Seuil | 전환의 문턱: 첫발, 떠남, 건너감, 멈춤, 되돌아감 | career event |
| Surroundings | 나와 Thread가 겹치는 장면들 | recommendations |
| Dérive | 돌아보는 길 일곱 걸음의 회고 | survey, assessment, test |
| Tracé | 회고를 마치고 남긴 결과 (편지, 길 그림) | report, result score |
| Archive | 사람들이 남긴 장면 전체 | feed |

내부 탭 상태는 도시 판과 같다: `derive`, `map`, `archive`, `trace`. 화면 라벨은 `돌아보기`, `지도`, `발견`, `나의 길`.
