# User Flows — 커리어 판

## Archive discovery

앱 열기 → 지도(아직 내 위치 없음) → 장면 점 선택 → 카드 → 장면 상세 → 가져갈 질문.

## Dérive → Tracé

돌아보기 → 시작하기 → 일곱 질문(4번은 거쳐 온 곳 먼저) → 결과 편지 → 나의 길에 남기기 → 지도에 나의 흐릿한 영역이 나타남.

## Save target

장면 상세 → 나의 길에 담기 → 나의 길에서 확인. 계정 연동 전까지는 현재 세션에만 남는다.

## Critical states

- 회고 전: 지도에 내 위치가 없음을 말하고 돌아보기로 안내한다.
- 답을 고르지 않음, 직접 적기 칸이 빔, 거쳐 온 곳이 없음: "다음"을 막고 이유를 보여 준다.
- 회고 도중 그만두기, 결과를 남기지 않기: 확인을 받는다.
- 되풀이해 온 일을 고르지 않음: 영역은 넓고 흐릿하게, 상태 문구로 알린다.
