# Visual System

The interface is quiet, editorial, spatial, tactile, observant, and unhurried. Use restrained ink-on-paper colors, generous whitespace, serif editorial headings, legible sans-serif utility text, and imagery as the primary visual material.

Practical constraints:

- Preserve readable contrast and minimum comfortable touch targets.
- Do not compress layouts to expose more content.
- Do not introduce commercial badges, ratings, or dense dashboards.
- Reuse Figma-exported assets in `assets/figma/` when they are the approved source.
