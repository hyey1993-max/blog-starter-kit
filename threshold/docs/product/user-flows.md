# User Flows

## Archive discovery

Open app → location permission or location-free state → subjective map → inspect a Passage → read interpretation.

## Navigation

Place detail → choose navigation → Naver Map or KakaoMap handoff. THE THRESHOLD does not calculate or render the route.

## Dérive → Tracé

WALK tab → start Dérive → observe route/time → add photo or text observations → finish → review and save the Tracé.

## Save and curation target

Place detail → save → select or create a personal curation → verify on My Map. This remains a product target until persistence/auth UI is implemented.

## Critical states

Every critical flow must account for location denied, no nearby places, loading, recoverable error, external map unavailable, and unsaved walk state.
