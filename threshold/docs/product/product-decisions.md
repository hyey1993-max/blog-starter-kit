# Product Decisions

## Accepted

- Phase 1 uses human-curated cards and contextual tags.
- A map remains in the experience as a quiet spatial canvas.
- Static/owned map artwork and device GPS preserve the current zero-paid-map-API prototype.
- Navigation is delegated to Naver Map or KakaoMap.
- Proximity is an acceptable explainable ordering input.
- The main-screen Seuil slider was removed; Seuil remains domain metadata and may return only with a separately validated interaction.

## Deferred

- AI semantic discovery and vector search.
- Generic search as a primary interface.
- Live map SDK selection until real usability requires pan/zoom/marker geography.

## Rejected defaults

- Ratings, follower-count prominence, popularity ranking, and engagement ranking.
